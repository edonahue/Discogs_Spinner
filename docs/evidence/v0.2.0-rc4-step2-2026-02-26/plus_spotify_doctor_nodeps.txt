Missing Python dependency: typer

Install required system packages on Pop!_OS:
  sudo apt update && sudo apt install -y python3 python3-venv python3-pip python3-setuptools libsecret-1-0 build-essential python3-dev

Then install project dependencies:
  python3 -m venv .venv
  source .venv/bin/activate
  pip install -r requirements.txt
  pip install -e .
