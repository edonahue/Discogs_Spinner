# Unreleased Changes

This file tracks user-visible changes currently on `main` that may not be present
in the latest packaged public release.

Latest stable public release: `v0.2.0`

## Current Main

- Collection browse surfaces summary stats: LP count, 45 count, median value,
  and most-recently-added context.
- Desktop Browse and Wantlist gallery behavior includes scrollable gallery
  layouts and right-hand detail panes after selection.
- The desktop Value tab is expanding into a release value workspace with synced
  release search, selected-release inspection, Browse-to-Value handoff, and
  Hidden Gems.
- The web Value page includes top priced releases, Hidden Gems, refresh queue
  candidates, and collection handoff links.
- Queue behavior remains useful as a value-refresh workflow, but it is not a
  top-level desktop UI tab.

## Packaging Note

Do not describe these items as shipped installer behavior until the next release
artifacts are built, validated, and published on GitHub Releases.
