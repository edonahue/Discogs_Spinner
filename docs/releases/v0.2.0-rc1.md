# discogs_player v0.2.0-rc1

## Summary

- Release type: `rc`
- Tag: `v0.2.0-rc1`
- Date: `2026-02-26`
- Scope: first external-release candidate baseline for pilot-user installs, release automation, diagnostics, and provider scaffolding.

## Highlights

- Added release infrastructure:
  - tagged-release GitHub workflow (`v*` tags),
  - RC runbook and release-notes template,
  - staged release checklist and OS quickstarts.
- Added release readiness foundations:
  - legal/compliance docs (`LICENSE`, `PRIVACY.md`, `TERMS.md`, `TRADEMARKS.md`, `COMPLIANCE.md`),
  - prepublish hygiene gate script + CI job.
- Added supportability improvements:
  - issue templates for install/auth/playback,
  - `dplayer diagnostics` redacted support bundle.
- Added provider expansion scaffolding:
  - provider registry helpers,
  - listed-vs-enabled provider state,
  - experimental YouTube Music placeholder flag (`DP_ENABLE_EXPERIMENTAL_YOUTUBE_MUSIC`).
- Improved setup FTUX:
  - first-run checklist and action sequencing in setup report.

## Known Limitations

- Desktop deliverables are currently tarball artifacts, not native signed installers.
- macOS signing/notarization is not yet in place for this RC.
- Provider expansion beyond Spotify is scaffold-only (YouTube Music disabled by default).

## Upgrade / Migration Notes

- New command:
  - `dplayer diagnostics --json`
- New env flag (experimental provider scaffold):
  - `DP_ENABLE_EXPERIMENTAL_YOUTUBE_MUSIC=1`
- No DB schema migration required for this RC.
