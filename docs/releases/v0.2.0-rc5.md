# discogs_player v0.2.0-rc5

## Summary

- Release type: `rc`
- Tag: `v0.2.0-rc5`
- Date: `2026-02-27`
- Scope: modernized README as a product landing page; replaced synthetic screenshots with real GTK4 captures from a headless Xvfb session.

## Highlights

- Reworked root `README.md` into a concise product landing page with feature bullets, 2×2 screenshot grid, and clean quick start.
- Replaced all synthetic PIL-generated media with real screenshots captured from the live GTK4 app running under Xvfb — no desktop session required.
- Added `scripts/headless_screenshot.py`: drives the app headlessly, navigates views via GLib callbacks, captures via python-xlib.
- Added `scripts/capture_readme_media.sh`: guided/automated capture for live desktop sessions.
- Updated `scripts/generate_readme_media.py` and `docs/media/README.md` to reflect new filenames and capture-first workflow.

## Known Limitations

- Debian clean-machine install validation remains environment-sensitive when package index DNS is unavailable.
- GUI launcher runtime checks can fail in headless sessions without a real desktop display stack.
- External playback remains provider-dependent and is intentionally out-of-process (no in-app streaming).
