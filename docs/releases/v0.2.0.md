# discogs_player v0.2.0

## Summary

- Release type: `stable`
- Tag: `v0.2.0`
- Date: `2026-03-30`
- Scope: first public installer-first release for Linux, Windows, and macOS.

## Highlights

- Native installers are now the primary release story across all three operating systems.
- The cross-platform installer pipeline now validates bundled `dplayer-api` sidecars before publishing assets.
- Linux desktop packaging, Windows installer validation, and macOS bundle validation have been hardened into a single release flow.

## Packaging And Distribution

- Artifacts included:
  - Windows `.msi`
  - Windows NSIS `.exe`
  - macOS `.dmg`
  - Linux Tauri `.deb`
  - Linux `.AppImage`
  - Linux GTK desktop `.deb`
- Checksum manifest: `CHECKSUMS-INSTALLERS.txt`
- Build workflow: `Installer Build`

- Debian quickstart: [docs/quickstart_debian.md](../quickstart_debian.md)

## Known Limitations

- macOS builds are currently unsigned and may require a one-time Gatekeeper quarantine removal.
- Windows builds may show SmartScreen warnings until signing is added.
- Windows installer confidence now includes the slower MSI runtime smoke lane, but code signing is still future work.

## Upgrade / Migration Notes

- Breaking changes: none.
- Existing local data and config paths are unchanged.
- The public release path is now installer-first; source installs remain available for advanced CLI and development workflows.
